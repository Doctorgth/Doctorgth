### 🌐 [APTCP (Persistent TCP)](https://github.com/Doctorgth/PTCP)
**Реализация сеансового протокола (L5) поверх стандартного TCP для удержания соединений.**
*   **Решаемая проблема:** Прозрачное удержание логических соединений при смене IP-адресов клиента (Wi-Fi/LTE) и микро-обрывах сети.
*   **Особенности:** Рукопожатие Диффи-Хеллмана (2048-bit MODP), авторизация возобновления сессий через HMAC-SHA256, встроенный контроль переполнения буферов (Backpressure) в User-Space. Нативная поддержка защищенных соединений SSL/TLS (совместимо с `ssl.SSLContext`).
*   **Статус:** Пакет опубликован на PyPI (`pip install aioptcp`).

### 🔒 [APTCP-SOCKS5 Proxy](https://github.com/Doctorgth/PTCP) (В разработке)
**Высокопроизводительный прокси-сервер на базе протокола APTCP для стабильного гейминга.**
*   **Идея:** Прокси-сервер, который можно развернуть на любой бюджетной VPS. Благодаря APTCP-подложке, соединение в играх или терминалах не рвется при микро-обрывах мобильного интернета и перегрузках канала.
*   **Стек:** Python, Asyncio, SOCKS5, APTCP.

### 🧠 [Live-Context AI Chat](https://github.com/Doctorgth/live-context-ai-chat) 
**Десктопный ИИ-ассистент разработчика с живым контекстом файлов, поддержкой Gemini 3.6 Flash, движком Multi-Canvas и исполнителем FS-XML.**

*   **Решаемая проблема:** Существующие ИИ-чаты требуют ручного копирования кода при каждом изменении, быстро забивают контекст лишней историей и не умеют безопасно модифицировать локальные файлы на диске.
*   **Ключевой функционал:**
    *   **Поддержка новейших LLM:** Полный доступ к **Gemini 3.6 Flash**, Gemini 3.5 Flash Lite, Gemma 4, а также локальным моделям через OpenAI-совместимый API (Ollama, LM Studio, vLLM).
    *   **Уникальный движок Multi-Canvas:** Модель анализирует актуальное состояние кодовой базы и предлагает автоматические патчи. Изменения визуализируются в формате интерактивных Diff-блоков с умной подгонкой отступов (Smart Indent Adjustment) и возможностью применения (`apply`) или отката (`rollback`) прямо из чата.
    *   **Агентский режим и исполнитель [FS-XML](https://github.com/Doctorgth/FS-XML):** Встроенный парсер и исполнитель файловых команд (`<fs_create>`, `<fs_edit>`) с автодобавлением созданных файлов в контекст и защитой файлов в режиме `Read-Only`.
    *   **Живой контекст без ручного обновления:** Прямая асинхронная инжекция файлов проекта с диска. Модель мгновенно видит любые физические изменения в файлах.
    *   **Управление памятью и закрепы (📌 Pinning):** Настройка глубины истории для точного контроля расхода токенов (`tiktoken`) и закрепление важного ТЗ, которое никогда не вымывается из памяти.
    *   **Безопасность и шифрование:** Хранение API-ключей в зашифрованном виде (AES-Fernet) с привязкой к системному хранилищу ОС (Windows DPAPI / Keychain).
    *   **Глубокая кастомизация интерфейса:** Кастомные темы Catppuccin, поддержка фоновых изображений, прозрачности и эффекта Glassmorphism (blur), мультиязычность (RU/EN).
*   **Стек:** Python 3.13+, FastAPI, SQLite (aiosqlite + SQLAlchemy 2.0), Google GenAI SDK, Vue 3 (Vite, Pinia, Tailwind CSS), pywebview.
*   **Лицензия:** Apache License 2.0.


###  [FS-XML Interpreter](https://github.com/Doctorgth/FS-XML) (Версия v1.0.0)
**Графическое приложение (GUI) для безопасного автоматического применения изменений в кодовой базе на основе ИИ-инструкций.**
*   **Решаемая проблема:** Нейросети часто выдают разрозненные фрагменты кода для разных файлов, требуя ручного копирования. Приложение автоматизирует и защищает этот процесс по спецификации **FS-XML v1.2**.
*   **Ключевой функционал:**
    *   **Мгновенный импорт ответов ИИ:** Парсер извлекает валидные XML-инструкции напрямую из скопированного сообщения ИИ, игнорируя маркдаун-верстку, приветствия и лишний текст.
    *   **Разграничение прав доступа:** Древовидный выбор файлов контекста с правами `Writable` (разрешено менять) и `Read-Only` (только для чтения ИИ).
    *   **Генератор контекста:** Сборка чистого дампа кодовой базы (`context_dump.txt`) с автопропуском бинарников.
    *   **История изменений и Откаты (Rollback):** Запись снимков файлов (snapshots) в SQLite. Возможность мгновенно откатить или применить повторно любую сессию правок, а также защита от затирания ручных изменений разработчика.
    *   **Портативность и визуал:** Автономная сборка (Windows Embed) с нативным легковесным лаунчером на C# и стильным полупрозрачным интерфейсом (Glassmorphism).
*   **Стек:** Python, PySide6 (Qt6), SQLite, C# (лаунчер).
