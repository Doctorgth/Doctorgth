## 🛠 Активные Open-Source проекты

Большая часть моей коммерческой работы скрыта под NDA, поэтому здесь я публикую свои независимые системные разработки:

### 🌐 [APTCP (Persistent TCP)](https://github.com/Doctorgth/PTCP)
**Реализация сеансового протокола (L5) поверх стандартного TCP для удержания соединений.**
*   **Решаемая проблема:** Прозрачное удержание логических соединений при смене IP-адресов клиента (Wi-Fi/LTE) и микро-обрывах сети.
*   **Особенности:** Рукопожатие Диффи-Хеллмана (2048-bit MODP), авторизация возобновления сессий через HMAC-SHA256, встроенный контроль переполнения буферов (Backpressure) в User-Space.
*   **Статус:** Пакет опубликован на PyPI (`pip install aioptcp`).

### 🔒 [APTCP-SOCKS5 Proxy](https://github.com/Doctorgth/PTCP) (В разработке)
**Высокопроизводительный прокси-сервер на базе протокола APTCP для стабильного гейминга.**
*   **Идея:** Прокси-сервер, который можно развернуть на любой бюджетной VPS. Благодаря APTCP-подложке, соединение в играх или терминалах не рвется при микро-обрывах мобильного интернета и перегрузках канала.
*   **Стек:** Python, Asyncio, SOCKS5, APTCP.

### 🧠 [Live-Context AI Chat](https://github.com/Doctorgth/PTCP) (В разработке / Готов бэкенд)
**Локальный ИИ-ассистент разработчика с живым контекстом файлов и уникальным движком Multi-Canvas.**
*   **Решаемая проблема:** Существующие ИИ-чаты требуют ручного копирования кода при каждом изменении, быстро забивают контекст лишней историей и не умеют безопасно модифицировать локальные файлы.
*   **Ключевой функционал:**
    *   **Уникальный движок Multi-Canvas (Аналогов в open-source нет):** Модель анализирует актуальное состояние кодовой базы и предлагает автоматические патчи сразу для нескольких файлов. Изменения визуализируются в формате интерактивных Diff-блоков с возможностью мгновенного применения (`apply`) или безопасного отката (`rollback`) прямо из чата.
    *   **Живой контекст без ручного обновления:** Прямая асинхронная инжекция файлов проекта с диска. Модель мгновенно видит любые физические изменения в файлах, избавляя от необходимости постоянно прикреплять их заново.
    *   **Управление глубиной памяти:** Настройка жестких лимитов истории чата для удержания фокуса модели на текущей задаче, чтобы предотвратить размытие внимания на больших объемах токенов.
    *   **Закрепление планов (Pinned Messages):** Важные сообщения (планы разработки, правила форматирования) жестко фиксируются в контексте и никогда не вымываются.
    *   **Workspace-изоляция:** Разделение задач на независимые проекты со своими индивидуальными файлами контекста и системными промптами.
    *   **Полнотекстовый поиск:** Локальный поиск по сообщениям и коду внутри всей истории воркспейсов.
    *   **Глубокая кастомизация интерфейса:** Поддержка пользовательских цветовых схем и размытия (blur) фоновых изображений.
*   **Стек:** FastAPI, SQLite (aiosqlite + SQLAlchemy 2.0), Google GenAI SDK, cryptography, keyring, tiktoken.
*   **Лицензия:** Apache License 2.0.
