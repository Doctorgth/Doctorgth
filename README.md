### 🌐 Сетевые протоколы и отказоустойчивая инфраструктура

#### 🚀 [APTCP (aioptcp)](https://github.com/Doctorgth/PTCP)
**Асинхронная реализация сеансового протокола (L5) поверх TCP для бесшовного удержания соединений.**
* **Решаемая проблема:** Устранение разрывов пользовательских сессий при смене IP-адресов (Wi-Fi ↔ LTE), нестабильном канале связи и микро-обрывах.
* **Архитектурные особенности:** Первичный обмен ключами по схеме Диффи-Хеллмана (2048-bit MODP), авторизация возобновления сессий через HMAC-SHA256 (3-way challenge-response), защита от переполнения памяти в User-Space (Backpressure / Flow Control), нативная поддержка TLS (`ssl.SSLContext`).
* **Статус:** Опубликован на PyPI (`pip install aioptcp`).

#### ⚡ [APTCP-SOCKS Tunnel](https://github.com/Doctorgth/APTCP-SOCKS)
**Высокопроизводительный отказоустойчивый SOCKS5 прокси-сервер и туннель на базе сессионного протокола APTCP.**
* **Возможности:** Полная поддержка SOCKS5 (RFC 1928), включая `TCP CONNECT` и двустороннее туннелирование UDP-датаграмм (`UDP ASSOCIATE`).
* **Безопасность и авторизация:** Двухуровневая аутентификация (локальная RFC 1929 + туннельная сессионная авторизация через JSONL), сквозное TLS-шифрование с проверкой сертификатов.
* **Развертывание:** Готовые Docker Compose конфигурации и скрипт автоматической установки `install.sh` для Linux.

#### 🐱 [NekoFlow](https://github.com/Doctorgth/nekoflow)
**Графический клиент сетевого туннелирования для Windows на базе протокола APTCP.**
* **Режимы работы:**
  * **TUN Mode:** Перехват системного трафика через виртуальный адаптер Wintun и маршрутизатор `sing-box`. Поддержка раздельного туннелирования (**Split Tunneling**) по белым спискам процессов и глобального режима.
  * **SOCKS Proxy Mode:** Локальный изолированный прокси-сервер (`127.0.0.1:3080`) для перенаправления отдельных приложений через Proxifier/Postern без вмешательства в системную таблицу маршрутов.
* **Поставка:** Portable-сборка с нативным лаунчером на C#, встроенным интерпретатором Python 3.12 и современным UI на PySide6 (Qt6).

### 🛡 Инструменты сетевой безопасности и отладки

#### 🔍 [NetDbg](https://github.com/Doctorgth/NetDbg)
**Модульный сетевой отладчик, SOCKS5 прокси-сервер и инжектор пакетов для анализа и реверс-инжиниринга сетевых протоколов.**
* **Потоковый фрейминг (Packet Framer):** Разбор непрерывного TCP-потока на дискретные пакеты с поддержкой порядков байт Little-Endian и Big-Endian, настраиваемых заголовков длины, опкодов и режимов включения заголовков (`include_len`).
* **Перехват и инъекция:** Буферизация трафика с фильтрацией на лету (по IP, порту, опкоду, направлению), эмуляция ответов сервера и запросов клиента (всеядный HEX-парсер), воспроизведение дампов (Replay) и покадровая отправка.
* **Архитектура:** Standalone GUI на Tkinter + C# лаунчер, а также CLI-демон для автоматизации и интеграции по протоколу JSON-IPC (stdin/stdout).

### 🧠 AI & Developer Tooling

#### 💬 [Live-Context AI Chat](https://github.com/Doctorgth/live-context-ai-chat)
**Десктопный ИИ-ассистент разработчика с живым контекстом файлов, поддержкой Gemini API, движком Multi-Canvas и исполнителем FS-XML.**
* **Живой контекст с диска (Live Context):** Асинхронное считывание файлов перед каждым запросом — модель всегда видит актуальный код без ручного копирования.
* **Multi-Canvas Auto-Patching:** Автоматический расчет смещения отступов (Smart Indent Adjustment) и применение интерактивных Diff-патчей к файлам прямо из чата.
* **Поддержка моделей:** Google Gemini (Gemini 2.5/3.0/3.5 Flash, Gemma) через официальный SDK `google-genai`, а также локальные и облачные LLM через OpenAI-совместимый API (Ollama, LM Studio, vLLM).
* **Управление контекстом и безопасность:** Скользящее окно памяти + закрепы (📌 Pinning), расчет токенов через `tiktoken`, шифрование API-ключей (AES-Fernet + Windows DPAPI / Keyring).
* **Стек:** FastAPI, SQLite (aiosqlite + SQLAlchemy 2.0), Vue 3 (Vite, Pinia, Tailwind CSS, Glassmorphism UI).

#### 📑 [FS-XML Interpreter](https://github.com/Doctorgth/FS-XML)
**GUI-приложение для безопасного пакетного применения правок кода, сгенерированных нейросетями, по спецификации FS-XML v1.2.**
* **Парсер и исполнитель:** Извлечение команд создания (`<fs_create>`) и модификации файлов (`<fs_edit>` с поиском/заменой `<fs_search>`/`<fs_replace>` или полной перезаписью `<all />`) из "сырых" ответов LLM.
* **Безопасность и откаты (Rollback):** Разграничение прав (`Writable` / `Read-Only`), защита от Path Traversal (`../../`), создание снимков (snapshots) в SQLite для мгновенного отката или повторного применения сессий с детекцией ручных правок.
* **Стек:** Python, PySide6 (Qt6), SQLite, C# лаунчер.
